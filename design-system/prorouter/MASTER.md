## Style Guidelines

**Style:** Minimalism & Swiss Style

**Keywords:** Clean, simple, spacious, functional, white space, high contrast, geometric, sans-serif, grid-based, essential

**Best For:** Enterprise apps, dashboards, documentation sites, SaaS platforms, professional tools

**Key Effects:** Subtle hover (200-250ms), smooth transitions, sharp shadows if any, clear type hierarchy, fast loading

### Page Pattern

**Pattern Name:** FAQ/Documentation Landing

- **Conversion Strategy:** Reduce support tickets. Track search analytics. Show related articles. Contact escalation path.
- **CTA Placement:** Search bar prominent + Contact CTA for unresolved questions
- **Section Order:** Hero with search bar > Popular categories > FAQ accordion > Contact/support CTA

## Project Implementation Decisions (2026-10-16 rebuild)

> These implement the rules above in `apps/web`. Follow them when adding UI.

- **Mode:** dark-only (user-confirmed). Tokens are structured so a light theme can be added in `globals.css` + `layout.tsx` only.
- **Accent:** emerald `#22C55E` (skill recommendation, user-confirmed). Text on accent fills = `#052E16` (`--color-accent-ink`).
- **Token mapping used in Tailwind (`@theme` in `apps/web/app/globals.css`):** `ink`=page bg `#020617`, `ink2`=sidebar/alt `#060B1A`, `panel`=card `#0E1223`, `panel2`=popover `#141A30`, `line/line2`=hairline borders (slate @ 14%/26%), `fg`=`#F8FAFC`, `mut`=`#94A3B8`, `mut2`=`#738199`, `accent`=`#22C55E`, `accent2`=`#4ADE80`, `accent-ink`=`#052E16`, `good`=`#22C55E`, `warn`=`#F59E0B`, `bad`=`#EF4444`.
- **Typography:** Inter (sans) + JetBrains Mono (mono) via `next/font/google` in `layout.tsx`; numbers/IDs in `font-mono tabular-nums`.
- **Icons:** `lucide-react` only — no emojis/unicode glyphs as structural icons. 14/16px, strokeWidth 1.75 for chrome, default 2 in body where already used.
- **Effects:** color-only hover transitions `duration-200`; no gradients, no glow shadows, no layout-shifting hover transforms. Blueprint grid backdrop via `.grid-backdrop`. FAQ/accordion "+" is an inline SVG that rotates 45°.
- **Interactive primitives:** `apps/web/components/ui.tsx` (`Button`, `IconButton`, `CopyButton`, `Badge`, `Card`, `Input`(trailing slot), `Textarea`, `Select`, `Skeleton`, `EmptyState`, `Modal`, `Toast`). Button-styled links use the `linkButtonPrimary/Secondary/Ghost` class strings as in `app/dashboard/page.tsx`.
- **Charts:** dependency-free `components/Charts.tsx` (`BarChart` with hairline gridlines + zero-activity empty state, `UsageBars`, `Sparkline`).
- **Page-level overrides:** none created yet — add `design-system/prorouter/pages/[page].md` when a page must deviate.

## Anti-Patterns (Do NOT Use)

- ❌ Buried endpoints
- ❌ Broken version switching
- ❌ missing rate-limit state

### Additional Forbidden Patterns

- ❌ **Emojis as icons** — Use SVG icons (Heroicons, Lucide, Simple Icons)
- ❌ **Missing cursor:pointer** — All clickable elements must have cursor:pointer
- ❌ **Layout-shifting hovers** — Avoid scale transforms that shift layout
- ❌ **Low contrast text** — Maintain 4.5:1 minimum contrast ratio
- ❌ **Instant state changes** — Always use transitions (150-300ms)
- ❌ **Invisible focus states** — Focus states must be visible for a11y

## Pre-Delivery Checklist

Before delivering any UI code, verify:

- [ ] No emojis used as icons (use SVG instead)
- [ ] All icons from consistent icon set (Heroicons/Lucide)
- [ ] `cursor-pointer` on all clickable elements
- [ ] Hover states with smooth transitions (150-300ms)
- [ ] Light mode: text contrast 4.5:1 minimum
- [ ] Focus states visible for keyboard navigation
- [ ] `prefers-reduced-motion` respected
- [ ] Responsive: 375px, 768px, 1024px, 1440px
- [ ] No content hidden behind fixed navbars
- [ ] No horizontal scroll on mobile
